# Security Policy

RHBurnerPass v0.1 is experimental and unaudited. Use Robinhood Chain Testnet only.

## Never do this

- Never submit a seed phrase or private key to the RHBurnerPass frontend.
- Never commit `.env`, `.env.local`, or deployment keys to GitHub.
- Never use a valuable mainnet wallet during alpha testing.

## Reporting

Open a GitHub issue for non-sensitive bugs. For a real deployment, add a private security-reporting channel before mainnet.
